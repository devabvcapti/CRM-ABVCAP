# CRM ABVCAP

CRM de inteligência de relacionamento institucional para a Associação Brasileira de Private Equity e Venture Capital (ABVCAP). Foco em memória institucional, disciplina operacional e inteligência de rede — não é um CRM de vendas.

Stack: Next.js (App Router) + TypeScript + Tailwind/shadcn + Supabase (Postgres, Auth, RLS, Realtime, Storage) + Vercel.
